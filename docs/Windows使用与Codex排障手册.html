Branch Desk Windows 使用说明

Windows 10/11 x64 用户级安装，Python 与 .NET 已随包提供。需安装 Git for Windows 和 Microsoft Edge WebView2 Runtime。

  1. 从桌面或开始菜单打开 Branch Desk。
  2. 点击“添加本地项目…”，选择已克隆到本机的 Git 仓库目录。
  3. 点击“启动 / 连接工作台”，查看分支、差异和工作区。

Node、JDK、Codex CLI 及飞书账号按项目需要配置。关闭窗口保留后台。升级前从“更多操作”菜单关闭所有空闲工作台后台，然后关闭窗口；业务服务单独停止。

配置与日志：%LOCALAPPDATA%\Branch Desk。不要分享包含会话凭证的本地 URL。启动失败时检查 Git 的 PATH、项目是否为 Git 仓库及 WebView2 Runtime。

Windows 设置的“已安装的应用”中可以卸载 Branch Desk，用户配置与代码仓库保留。详细验证范围见同目录的“发布验证说明.md”。
